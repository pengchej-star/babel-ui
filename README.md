# Babel UI

一个只跑在本机的 Babel（Slurm）面板：作业 / 日志 / GPU 利用率、历史作业、申请资源、各节点 GPU 占用、文件浏览与上传下载、网页终端、作业通知。

集群上什么都不用装。所有数据都是本机 `ssh babel` 上去执行 `squeue` / `scontrol` / `sacct` / `sbatch --test-only` 等命令拿到的。

## 运行

```bash
pip install aiohttp keyring
python3 server.py
```

打开 http://127.0.0.1:8765 。

**第一次需要登录**：「终端」页会弹出 ssh 的密码 / Duo 提示，登录一次后左上角变绿，其它页自动开始刷新。
连接通过 ssh ControlMaster 复用（socket 在 `~/.ssh/babel-ui-*`），保持 8 小时，期间重开页面或终端都不用再登录。

**自动登录（可选）**：点右上角 🔑 保存密码。密码存进 macOS 钥匙串（`keyring` 库，服务名 `babel-ui`），不落盘、不进环境变量，网页也读不回来。之后连接断开时，服务会通过 `SSH_ASKPASS`（[askpass.py](askpass.py)）自动登录；遇到 Duo 提示会选 1（推送），在手机上确认即可。
自动登录失败一次就停，直到你在 🔑 里点「立即登录」或保存新密码，避免错误密码反复尝试把账号锁掉。

依赖 `~/.ssh/config` 里有 `Host babel`；别的名字用 `BABEL_HOST=xxx python3 server.py`，换端口用 `PORT=`。

## 功能

- **作业**：`squeue -u $USER`，每 10 秒刷新；✕ 调 `scancel`（会先确认）。底部是集群各分区运行 / 排队数。
  - **点一行打开详情**：实时跟踪 stdout / stderr（增量读取，相当于 `tail -f`，可下载完整日志）；运行中的 GPU 作业会通过 `srun --overlap` 在节点上跑 `nvidia-smi`，显示每块卡的算力和显存利用率，利用率过低会提醒。
  - **系统通知**：作业开始运行、结束（完成 / 失败 / 超时等）时弹 macOS 通知。由服务端每 30 秒检查一次，页面关着也会通知；勾选框可关闭。
- **历史**：`sacct` 最近 1 / 7 / 30 天的作业，含退出码、用时、资源。点一行看详情和日志。「重新提交」把 `cd 原目录 && 原 sbatch 命令` 放进终端但不回车——`sacct` 记录的命令丢了引号，需要你确认一下再按回车。（Babel 没开 `AccountingStoreFlags=job_script`，存不了作业脚本本身。）
- **申请**：选分区 / 卡型 / 卡数 / CPU / 内存 / 时长：
  - 「预估开始时间」用 `sbatch --test-only` 问调度器，不会提交作业；
  - 「开交互式会话」：Babel 的 preempt 只允许 `sbatch`（`salloc` 会被拒），所以先提交一个 `sleep infinity` 的占位作业，开始运行后用 `srun --jobid --overlap --pty` 进计算节点的 shell；exit 或等待时 Ctrl-C 都会自动 `scancel` 释放；
  - 「复制 #SBATCH 头」复制对应的脚本头。
  分区列表只列你的 QoS 能提交的（从 `sacctmgr` 的 association 推出来），会自动带上对应的 `--qos`。
- **GPU**：`scontrol show node`，每 20 秒刷新。每块卡一个格子，空卡多的节点排前面；下拉框按分区筛选（你能用的分区带 ✓ 排在前面），顶部按卡型统计，点卡型再筛；你的作业所在节点名会高亮。
  "空闲"只算真正调度得上的卡，另外两种空卡单独显示：
  - **空闲但预留**（空心）：节点是 `PLANNED`，调度器已把空闲资源留给排队中的作业，短作业也许能 backfill 进去。
  - **卡空但缺 CPU**（斜纹）：卡空着但节点 CPU 或内存已分配完，申请不到。
- **文件**：点目录进入；行尾 ⬇ 下载（目录打包成 .tar.gz）；「上传」或直接把文件拖进来，传到当前目录（不会覆盖同名文件）；"分析占用"对当前目录跑 `du -d1` 画条形图；"终端 cd 到此"把终端切到当前目录。
  - **在线编辑**：点文件用代码编辑器（CodeMirror，按扩展名 / shebang 高亮）打开，「保存」或 ⌘S 写回 Babel。写入是原子的（先写临时文件再 `mv`，保留原权限）；如果打开之后文件在 Babel 上被改过（比如作业在写），保存会提示冲突，由你决定覆盖还是放弃。二进制、非 UTF-8 或超过 2MB 的文件只提供下载。
  - **整理目录**：勾选行后可以复制 / 剪切 / 重命名 / 删除，切到目标目录点「粘贴到这里」；工具栏有新建文件夹 / 新建文件。粘贴不会覆盖同名项（移动时跳过并提示，复制到同一目录自动加 `_copy` 后缀）。删除是永久的（Babel 没有回收站），会列出要删的项让你确认；服务端拒绝删除或移动顶层目录、你的主目录和 `/data/user_data/$USER` 这类个人根目录。
- **终端**：完整的 ssh 会话（xterm.js），支持 vim / tmux。

## 安全

- 只监听 `127.0.0.1`，并拒绝其它网页的跨站请求 / WebSocket。
- 密码只在你主动保存时存进 macOS 钥匙串；否则认证完全交给你本机的 ssh。
- 申请资源的参数在服务端按白名单校验后才拼进命令。
